Toggle mode

Toggle mode allows you to send events depending on the state of the Button - Pressed or Released Event host should be marked by $P$ or $R$ prefix
$R$ http://192.1...
Event will be sent if the Button state is Released
$P$ http://192.1...
Event will be sent if the Button state is Pressed

Keystore

Event host should be marked with $K$ prefix
$K$ http://192.1...
Event will be sent on Keysore update
Update keystore URL:
http://%IP%/keystore?delay=DELAY&key1=DATA&key2=DATA&key3...
delay - if provided, send events will be initiated after delay, ms
Use $key$ expression for event data, and it will be replaced by corresponding value
